A program that writes one out-of-office auto-reply as if a houseplant sent it — the fern in the corner, unwatered since March, growing toward the door. One line, 110 characters, for the [Houseplant Out-of-Office bounty on make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047?ref=63s6rw9w).

## Run

```sh
node main.ts
```

It writes the reply to `MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is not set). Node 22, standard library only, deterministic, offline.
